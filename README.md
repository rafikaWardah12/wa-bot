# WA Bot
This project develops a WhatsApp bot designed to simplify administrative services by integrating with Google Spreadsheet, allowing users to track the progress of their administrative processes. In addition, users can access various service-related information.

## Features
* **Information Center**: Provides various administrative service information from the sub-district office, including required documents and prerequisites, via WhatsApp.
* **Online Tracking**: Tracks the progress of the service process.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/rafikaWardah12/wa-bot.git
    ```
2. Run project
   ```bash
   npm install
   ```
   ```bash
   npm run dev
   ```
3. Link the device
